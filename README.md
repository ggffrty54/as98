# A.S.98 — Маркетплейс одежды

Веб-приложение маркетплейса одежды и обуви **A.S.98**, разработанное на PHP для локального сервера Open Server Panel.

## Основные возможности
* **Витрина товаров:** отображение карточек с фотографиями, размерами и ценами.
* **Фильтрация и поиск:** быстрый отбор по категориям, живой поиск по названию и сортировка по цене (дешевле / дороже).
* **Корзина покупателя:** добавление вещей и автоматический подсчет общей суммы заказа.
* **Кабинет продавца (`seller.php`):** закрытый раздел с загрузкой новых товаров с фото с компьютера и управлением ассортиментом.

## Как запустить проект
1. Поместите папку проекта в директорию `home` в **Open Server Panel 6**.
2. Включите модули **PHP (8.1+)** и **Nginx / Apache**.
3. Откройте сайт в браузере по адресу `http://as98.local`.
4. Для входа в **Кабинет продавца** используйте пароль по умолчанию: `1234`.
